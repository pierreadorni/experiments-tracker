## Boundary summary

There is a strong execution boundary: `legacy_archive.execution_frozen` means
`execution_contract != 3`; `Workflow.advance`, `agent_stage`,
`_submit_prepared_stage`, normal agent dispatch, and title dispatch check it.
`Store.archive_legacy_experiments` marks only nonterminal old records, and
`Store.update` preserves that hold. The observer routes frozen saved jobs to
`legacy_archive.settle_job` before output checks and continues without
validation, registration, or stage advancement. Exact saved action settlement
is separate and does not call validators or continuations.

The remaining `if not iteration.enabled(...)` and old-recipe branches need
classification, not bulk removal. Some are unreachable execution fallbacks
after archival; others are retained saved-record validators/readers; still
others protect shared contract-3 behavior such as explicit script-less Slurm
stages, selective reuse, project resource authorization, and current output
validation. Schema 1/2 remains part of the record-reading contract even though
new experiments require execution contract 3 and plan schema 3.
