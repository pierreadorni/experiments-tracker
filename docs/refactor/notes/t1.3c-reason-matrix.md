# T1.3c experiment hold reason/source matrix

Status: read-only preparation for c1 expansion. Audited root source `e6447a6`
and the accepted [derived-hold design](t1.3c-derived-design.md) and
[hold inventory](t1.3c-hold-inventory.md). No production or live state changed.
This matrix covers only `experiments.hold_reason`; similarly named run,
discussion, project-turn and action-interrupt fields are separate.

## Saved-source rules

The advancement decision is always the experiment-lifetime backend
`reconcile` obligation targeting the experiment. A source-backed decision must
reference one exact source and agree with its scope, phase/evidence generation,
kind, owner and wait. A source-less condition remains advancement/backend work.
An exact current wait can be represented as `source:<obligation-id>` on the
advancement record; the source obligation retains its own wait below. Do not map
from error text, a status label alone, or the highest-priority display row.

Current c1a accepts only `None/none` plus these ten source-less pairs:

| Reason | Advancement wait |
|---|---|
| `agent_busy` | `admission:agent_busy` |
| `agent_paused` | `admission:agent_paused` |
| `agent_unavailable` | `backend:agent_unavailable` |
| `compute_busy` | `admission:compute_busy` |
| `executor_unavailable` | `backend:executor_unavailable` |
| `new_compute_paused` | `admission:new_compute_paused` |
| `project_busy` | `admission:project_busy` |
| `project_unavailable` | `backend:project_unavailable` |
| `quota_hold` | `admission:quota` |
| `workspace_unavailable` | `backend:workspace_unavailable` |

`quota_snapshots.id` is already saved and should be included as policy evidence
when a quota decision is written, but c1a's version-1 record has no such field.
The pause flags are saved experiment facts. Busy predicates may aggregate
several sources; use a source-less capacity wait when no single saved source is
the blocker.

The actual dynamic experiment hold vocabulary from `Autopilot.authority` and
`Autopilot.admission` is: `autopilot_project_unavailable`,
`autopilot_draft`, `autopilot_paused`, `autopilot_stopped`,
`autopilot_completed`, `autopilot_deferred`, `autopilot_not_started`,
`autopilot_handoff`, `autopilot_writing_scope`,
`autopilot_accounting_prerequisite`, `autopilot_accounting_unknown`,
`autopilot_job_exceeds_weekly_cap`, and `autopilot_weekly_gpu_limit`.
`autopilot_authority_changed` is additionally saved as an agent interrupt
reason and reaches `experiments.hold_reason` through `hold_active_action` for a
non-discussion lane. `owner_ceiling` is an interrupt reason used to suppress
automatic failure; it is not itself written to the experiment column.

## Out-of-scope columns and identity gaps

- `autopilot_runs.hold_reason` values such as `research_decision_needs_attention`
  and `autopilot_researcher_input` are run-scope. Do not import them into the
  experiment matrix. `autopilot_actions.interrupt_reason` is a separate action.
- `discussions.hold_reason` and `project_turns.hold_reason` may reuse strings
  such as `agent_busy`, `quota_hold` or `agent_dispatch_uncertain`; they are
  message- or project-turn scope. They are not experiment sources.
- `autopilot_stage_holds` has a usable composite identity, but no direct
  `autopilot_run`/member/control revision foreign key in that row. Preserve the
  separate run authority; do not claim the stage hold proves a current run
  status by itself.
- `pending_request` and `plan_review` embed generations on the experiment. The
  current writers notify separately, and do not persist a direct notice ID.
  `inbox` itself has a stable ID and uniqueness on `(experiment_id,kind,text)`;
  writer integration must capture/reuse that row in the same transaction.
- `agent_stage_blocked`/`agent_stage_failed` pseudo-jobs and agent actions lack
  a direct durable link. Use the exact action and its saved result; do not claim
  stage/revision is an exact action ID.
- `agent_wakeups.id` and `due_at` are exact timer identities for timer-backed
  work. No current experiment hold reason writes that timer identity; if a
  decision waits on it, use backend/`timer`/`timer:<id>` and validate due time.
- A source-less hold read must reject a reason/wait mismatch. A source-backed
  hold must reject foreign experiment/project, wrong target, wrong owner/kind,
  stale action phase/evidence, changed scheduler ID, wrong transfer direction,
  stale request/review generation, wrong report request/version, and closed or
  unrelated source. A terminal decision must not reopen a closed source.

## Bounded expansion order

Keep each implementation card below 450 changed source plus test lines; measure
and split before implementation if a family cannot retain its negative cases.

1. **c1b:** add the approved typed source-reference payload support needed for
   exact terminal and cancellation decisions; cover completed/failed retry
   lifetimes, cancellation with unsettled effects, historical terminal rows,
   archive policy and idempotent notice reuse. Do not reopen terminal rows.
2. **c1c1:** action and job source/reason/wait matrix, including pseudo-job
   exclusion, pending/dispatching/running exact turns, scheduler-ID handoff and
   failed terminal decisions.
3. **c1c2:** transfer and report-version/publication identities, including
   pending/failed/completed versions and independent artifact delivery.
4. **c1c3:** pending request, inbox notice, plan-review generation, steering
   request and saved wakeup identities; reject missing or stale notice/generation
   references rather than falling back to detail text.
5. **c1c4:** pure compatibility priority mapper and malformed/mismatched source
   matrix across all preceding families; preserve historical fallback for old
   schemas and verify active execution reads never use display priority.

These are proposed size splits for the named c1b/c1c design cards, not runtime
activation or new schema. Update the ordered task card before delegating any
split. c1a remains limited to its ten explicit source-less pairs; all unlisted
reason/wait pairs must continue to fail closed until their family is reviewed.
