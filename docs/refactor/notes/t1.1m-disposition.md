The test suite imports helpers from sibling test modules, so a module cannot be
deleted or re-signatured before its importers move:

   `test_agent_output_recovery`, `test_audit`, `test_controller`,
   `test_conversation`, `test_dag`, `test_knowledge`, `test_multi_experiment`,
   `test_projects`, `test_prompt_context`, `test_reporting`, `test_resources`,
   `test_workspaces`, `test_iteration`, `test_iteration_agent_stages`,
   `test_iteration_early_repair`, `test_iteration_autopilot`. It must keep its
   name and behaviour until every importer migrates, and the contract-3 modules
   import it too, so it should move to `tests/helpers.py` rather than disappear.

   `test_audit`, `test_conversation`, `test_knowledge`, `test_multi_experiment`,
   `test_reporting`. Every importer is a READER or CONVERT row, so `submit` can
   only be deleted after those four files plus `test_workflow` move.
3. `test_generic.PLAN`/`SOURCE` are imported by `test_local_outputs`,
   `test_resources`, `test_agent_output_recovery` (as `DAG_PLAN`) and
   `test_controller`, and mutated by `monkeypatch.setattr("test_generic.PLAN"…)`
   in `test_dag`/`test_resources`/`test_temporary_outputs`. `test_generic` cannot
   be deleted before its three probe rows and those modules migrate.

   contract-3 modules (`test_iteration`, `test_iteration_agent_stages`,
   `tests/scenario/`) and 11 legacy modules. `approve_plan` is already
   contract-agnostic: move it to `tests/helpers.py` first. `ImplementationAgent`
   goes last.
5. `test_projects.register` → `test_workspaces`; `test_steering.wait_for` →
   `test_title`; `test_reporting.document` → `test_conversation` (lazy import);
   `test_dag.PLAN` → `test_agent_output_recovery`; `test_controller.create` (toy)
