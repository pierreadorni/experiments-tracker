## h7b command-path mismatch to resolve before landing

The h7b gateway gate rejects frozen `retry_agent`, `summarize_title`, steering, and plan-review approve/revise, but leaves pause actions and plan-review cancel admissible. For a *nonterminal* frozen record, the earlier Store `archive_active` guard rejects every action except `cancel` and rejects every `plan_review` command. Thus gateway can accept a pause or plan-review cancel into its durable queue that the local Store will reject on delivery. The normal `/actions` cancel remains admissible end-to-end. The new gateway test covers a **terminal** legacy plan-review cancel, where `archive_active` is false; it does not cover this nonterminal mismatch. The UI still renders pause-agent/pause-compute buttons for nonterminal frozen records, although local Store rejects them. Align the gateway/UI with the intended active-archive policy or deliberately retain a supported pause/cancel path before landing h7b.

The h7b gateway diff also adds a special `/answers` gate for frozen records, but no gateway test exercises either a bound live discussion answer or rejection of an unbound/stale frozen answer. Local tests cover tick delivery and Store refusal cases, not the gateway projection-to-command branch. Add focused gateway proof before claiming that boundary covered. The local workflow test covers a valid, wrong-action, wrong-phase, wrong-state, expired, and not-ready case; wrong owning action/task completion is checked in code but not separately parameterized.
