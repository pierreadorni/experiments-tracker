refer to current source and the legacy inventory; they are scope estimates, not diff
counts. Each implementation card must remeasure `git diff --numstat` (source and tests
separately) before landing and split again if it reaches 500 changed lines. No source
or test files were changed for this investigation.

readers, store projections, gateway/web saved-projection display, schema-1/2 model
readers, `Preparation` as a model, `verify_snapshot`, and the legacy body of
`validate_stage`. Do not infer that a helper is deletable merely because its
execution caller is removed.

Keep `test_local_outputs.py`'s legacy failed-reconciliation rows on explicit static
legacy state until the exact legacy block in `Workflow.reconcile_outputs` is deleted:
the body after shared guards that uses `verify_project_sources`,
`artifacts.validate_stage`, `seal_local_outputs`, and its own registration
transaction/return (currently around 1650–1750). This includes the
`invalid_output`/`symlink` refusals and rollback test. The contract-3 M8d tests do
not replace those saved-legacy-record checks. Likewise, keep any remaining cleanup
tests until h.5 deletes the cleanup loop, and keep the sealed restart `[True]` case
through the T1.1b-1 late-settlement disposition.
