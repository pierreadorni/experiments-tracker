## Harness design

- **Scope/fixture:** `tests/scenario/__init__.py` and local `conftest.py`, built on
  the existing config fixture. Demo mode, local execution context, one session.
  Assert `max_sessions == 1`. Test modules use `test_iteration_scenario_*.py`,
  avoiding the historical autouse downgrade. Fake-unit tests without experiments
  need not use that prefix. No real scheduler, model or agent socket starts.
- **FakeClock:** capture real wall time at fixture setup; maintain independent
  epoch/monotonic counters and explicit `advance(seconds)`. Patch T1.2a clock
  functions only, not global time or asyncio. Verify all engine wall-time checks
  (including backoff, wakeups and observation timestamps) use clock indirection
  before claiming fake-time coverage. Real file mtimes are explicitly stamped
  from fake time where controller freshness checks read them.
- **FakeSlurm:** existing async submit/reconcile/observe/exact-identity cancel
  surface. Shared fake backend retains accepted intents, IDs and observations
  across workflow/adapter recreation. Program acceptance followed by lost response,
  non-acceptance, visibility/accounting lag, duplicate exact matches and unreachable
  queries. Reconcile returns one ID, `None`, or raises real `SubmissionUncertain`
  for duplicates. Accepted-then-lost submit raises `SubmissionUncertain` only after
  saving the external identity. Unreachable queries raise raw runtime/timeout
  errors. Unexpected discover/preflight calls fail loudly in these demo scenarios.
  Write only declared tiny synthetic fixtures if a scenario needs outputs.
- **FakeCodex:** `is_demo=True`, no-argument construction, `available`,
  `resolved_model`, `models`, `models_observed_at` and request/quota/activity
  handlers. Match session/begin/finish/read_turn/interrupt/reply/close signatures,
  including `additional_writable_roots` and `expected_prompt_hash`. Store exact
  dispatched inputs and thread/turn IDs in the retained fake backend and check
  expected input hashes. Script results/callbacks/gates; unexpected turns fail.
  Save acceptance before a lost begin response, which raises real
  `TransportError`/`TimeoutError`. Missing or unfinished readable turns raise
  `NeedsAttention`; failed/interrupted turns raise `TerminalTurnError`; unreadable
  thread access raises real RPC/transport/timeout errors. Do not invent a
  list-turns adapter method. Quota is explicitly synthetic and admitted.
- **run_until:** advance fake time and call only
  `Workflow.tick(force_observe=True)`. After each tick, await the workflow's actual
  task handles: agent/quota tasks on every lane, backup, output checks (their tuple
  task handles), evidence checks and cleanup tasks. Explicitly registered fake
  gates identify intentionally waiting tasks, which are reported rather than
  awaited indefinitely. Await task completion/signals, not arbitrary zero-delay
  yield counts. A real-time timeout is solely a failure detector with concise saved
  experiment/action/job/task diagnostics, never a progress condition. Do not use
  `tests/helpers.wait_until` or other real timed sleeps to drive a scenario.
- **Controller seam:** scenario 2 alone may use the existing
  `wf.controller.server = object()` sentinel so controller wakeups actually run
  in demo mode. Declare it explicitly and clear it before normal workflow close.
  No other non-engine toggles or mocked-out dispatch are permitted.

## Three scenario ports

1. **Blocked stage plus steering:** create contract 3 by normal command, script
   planning/preparation and approve through the ordinary `plan_review` command.
   Use this driver's waits, not the existing `approve_plan` timing helper. Reuse
   the tiny accepted PLAN where appropriate. Script a blocked agent stage, then
   send later steering; assert the hold clears, exactly one continuation carries
   its text, duplicate requests add nothing, and saved attempt/thread identities
   survive. Keep the detailed existing stage tests until equivalent coverage is
   demonstrated.
2. **Healthy long job, zero additional turns:** get to RUNNING through the engine
   with the fake adapters, rather than insert a job row. Record baseline action,
   turn and submission counts *after* required planning/preparation. Across long
   fake elapsed time and controller wakeups, assert no additional `begin`, monitor
   action, or submission. Cover progress telemetry and uninstrumented output;
   refresh synthetic progress and stdout mtime from FakeClock so an actually stale
   job is not incorrectly labelled healthy. No `wf.dispatch = AsyncMock()`.
   This ports the no-monitor-inference assertion in `test_monitor_usage.py`;
   existing setup turns remain legitimate, retained actions.
3. **Lost submission:** persist the actual dispatch intent, accept externally,
   then lose the submit response. Stop the first workflow before creating its
   replacement. Retain the same SQLite and fake external backend. During lag,
   assert the uncertain row survives and submit count stays one. Reveal the saved
   match and assert adoption of its exact job ID, one `job_reconciled` event and a
   cleared hold, with exactly one submission for that intent. Stopping at adoption
   is enough; this need not execute the whole graph to completion.

Fake-unit tests also cover duplicate matches, lag, lost begin and unreadable
threads. They prove fake controls, not T1.4 resolver behavior. Existing scenario
coverage is retained until the corresponding port proves its safety assertions.
